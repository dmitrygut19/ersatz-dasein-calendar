# Проверки

```sh
npm run build
npm run typecheck
npm test
npm run test:admin
```

Серверные проверки: HTTP/SQLite, миграции, доступ, типы, события, повторы, настройки, импорт и аналитика. test:admin проверяет состояния desktop/mobile и каталог. Браузерным тестам нужен установленный Google Chrome (Playwright channel chrome). Базы/отчёты создаются отдельно в artifacts/ и не входят в Git.

## Дополнительные сценарии

Финальная проверка текущей реализации (каждая команда сама запускает сервер и отдельную базу):

```sh
npx playwright install firefox webkit
node scripts/verify-backup.mjs
node scripts/verify-handoff.mjs
node scripts/verify-editor-final.mjs
```

verify-handoff проверяет Chromium (установленный Chrome), Firefox и WebKit: календарь и админку на 320/360/375/390/430/768/1024/1440/1920 px, 320×320 и 844×390; некорректные ответы, offline/500/retry, порядок ответов, границу года, API/ICS и поддельные параметры личности. Отсутствующий движок явно указывается в результате. verify-editor-final требует все три движка и проверяет удаление галереи, сохранность назначенных обложек после рестарта, ошибки/повтор/двойное сохранение, гонку поиска участников, прокрутку и фокус. Если Firefox не запускает управляющее соединение внутри песочницы Windows, запускать проверки в обычном терминале.

- verify-shared-admin.mjs — запуск стенда (render-start, открытая админка): общие данные календаря и админки, сохранение настроек при sync.
- verify-participation-url.mjs — извлечение ссылок участия.
- verify-ical-event-card.mjs — обновления карточек/iCal.
- verify-untyped-events.mjs — очередь, типы серии/выпуска, сохранность доступа при назначении и повторном импорте.
- verify-full-lodge-covers.mjs — оригиналы обложек, миграция, сохранность индивидуальных настроек и размеры.

Сохранённые verify-calendar-sync.mjs и verify-calendar-settings.mjs относятся к прежнему DOM. Они оставлены для истории и требуют адаптации, прежде чем использовать их как проверки текущего интерфейса. Тестовый режим и его проверки удалены 25.11.2026; синтетический набор scripts/seed.mjs используется только автотестами.

Запуск: node scripts/<имя>. Перед запуском читать настройки скрипта: часть целевых регрессий ожидает локальный сервер через CARD_REVIEW_URL или RELEASE_URL. Скрипты с изменением событий не направлять на рабочий сервер.

## Мобильная карточка

После сборки запустить npm run preview:community отдельно. В другом терминале задать CARD_REVIEW_URL=http://127.0.0.1:4390, затем:

```sh
node scripts/verify-mobile-event-dialog.mjs
node scripts/verify-sheet-drag.mjs
```

Проверяются закрытие/открытие, история/фокус, прокрутка, пейджер и непрерывность drag. Touch эмулируется Chromium; физические iOS/Android и Safari проверяются отдельно.

Старые скриншоты, отчёты релизов и проверки отменённых вариантов убраны из текущего дерева. Они восстанавливаются из истории Git до очистки. Не возвращать прежние seed-наборы или решения по старым отчётам.
