# Полные обложки лож

Оригинальные пользовательские SVG из Downloads, предоставлены 20.11.2026. Все 11 файлов побайтово совпали с актуальным экспортом Figma EBWvCn9vPbk5srpmyXmytQ, страница 599:15335. manifest.json содержит ID ноды, исходное имя файла и SHA-256.

Размеры 512×512, фон, лучи, орнамент, цвета, SVG-фильтры и пропорции сохранены. Файлы скопированы без оптимизации или правки содержимого. Автоматические назначения используют только подтверждённые привязки lodgeCoverUrl; неизвестные эмблемы не назначаются по догадке. Онбординг без обложки.

Маленькие иконки фильтров/тегов по-прежнему находятся в ../lodges/ и используют lodgeIconUrl. Полные обложки хранятся отдельно, чтобы не заменять эти иконки.

Все 11 вариантов доступны в галерее оформления. Пять без подтверждённой привязки названы по изображённому предмету; автоматически ложам/событиям не назначаются.
