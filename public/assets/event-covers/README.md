# Иллюстрации типов событий

Позднее 16.11 пользователь вернул прежнюю обложку Сатурналий `/assets/panel/2a38c.png`. Файл `saturnalia-spears.png` оставлен доступным в галерее, но больше не назначен типу. Описание его подключения ниже историческое.

Последующее дополнение 16.11: `saturnalia-spears.png` — пользовательский «Красный квадрат с двумя копьями.png» из Downloads. Назначен типу `demo-saturnalia` вместо прежней стандартной обложки; режим poster и тёмная палитра сохранены. Обложки/оформление отдельных выпусков не меняются. Следующие сведения об alpha/contain относятся только к трём светлым предметным иллюстрациям.

Оригинальные PNG предоставлены пользователем 16.11.2026. По его указанию скопированы из Downloads без преобразования; SHA-256 копий совпадает с исходниками. Все три файла — 1448×1086, с прозрачным alpha-каналом.

- `congress-temple.png`: «Дорический павильон с бронзовым лавровым венком-2.png» → тип «Конгресс» (`demo-congress`).
- `community-table.png`: «Круглый стол с оливковой ветвью-1.png» → тип «Встреча участников» (`demo-community-meeting`).
- `project-scrolls.png`: «Пергамент, свитки и бронзовый циркуль-3.png» → тип «Обсуждение проектов» (`demo-project-discussion`).

Пути зарегистрированы в существующем каталоге `src/lib/cover-examples.ts` и проходят обычную валидацию обложек. Режим — illustration, `object-fit:contain`; прозрачные области не обрезаны. Видимый объект занимает примерно 83–95% ширины и 81–93% высоты исходного холста. Изображения вписываются в доступную область; при длинном названии эта область уменьшается, пропорции сохраняются.

Обложка наследуется из типа события. Сидер связывает два известных демонстрационных примера с новыми типами по ID, без поиска слов в заголовках. Индивидуальные обложки/оформление в `event_occurrence_overrides` не изменяются. Тёмная тема Сатурналий сохранена, её обложка заменена последующим поручением, описанным выше.
